# DriveSelect: Midterm Project

**Topic:** Car rental website, built from my Figma wireframe.

**Pages:** Home, Fleet, Rules, About, Contact (navbar on every page).

**Features**
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`)
- Table: insurance tiers (`rules.html`). Forms: search widget (Home), filters (Fleet), booking form (Contact)
- CSS: classes and IDs, Flexbox (card price row), Grid (car cards, standards), positioning (fixed header, relative/absolute hero tag)
- Media queries: 992px (tablet) and 576px (mobile)
- Bootstrap 5: grid, utilities, navbar, accordion (FAQ), form controls
